# Raw evidence tools

Tools for a session where the owner performs gestures on a real iPhone while the Mac logs what
reaches it. They record, they decide nothing: unlike `Tests/checks/` there is no `ok` or `FAIL`, and
none of this is linked into Sill or run by CI. Everything they build or write goes to
`.build/evidence/`.

The shell here may set `DEVELOPER_DIR` to the Command Line Tools, which have no iOS SDK and no
`devicectl`. The TouchTrace scripts use `/Applications/Xcode.app/Contents/Developer` (override with
`SILL_XCODE`); the Mac tools build with whatever `xcrun swiftc` finds.

Timestamps line up across tools by uptime: TouchTrace's `t` is `UITouch.timestamp` (the iPhone's
uptime), eventtap's `t` is the Mac's `CGEventTimestamp` (nanoseconds since boot), and every tool also
writes wall-clock epoch seconds (`wall`/`wallEpoch`), the field to align the two machines by.

## touchtrace: every raw touch on the iPhone

```
Tests/evidence/touchtrace/run.sh                 # build, sign, install and launch on "iPhone Ivor"
Tests/evidence/touchtrace/run.sh --build-only
Tests/evidence/touchtrace/pull.sh                # copy Documents back, print counts per gesture
SILL_EVIDENCE_DEVICE=<udid|name> ...             # another device
```

A one-view UIKit app (`main.swift`, built with `swiftc`, bundle `me.ivor.sill.touchtrace`), signed by
hand with the team's wildcard development profile (`4G96FT99AH.*`, found in Xcode's profile folder,
and its own certificate). A big label shows the current step of a fixed script, G1 to G21: pointer
moves (slow, fast, to each edge), one-finger taps, pinches in and out (slow, fast), pinch then pan,
two-finger double taps and their near misses (slow, far apart, single, scroll), the bottom edge (rest
1 s, pass along, drag off) and a palm graze. Hold **▶** (top right) for 1 s for the next step, **◀**
(top left) to go back; touches on that top bar are not logged.

Each session is `Documents/touchtrace-<UTC time>.jsonl`; `latest.txt` names the newest. Records:
`session` (view 440×956 pt, scale 3, 120 Hz on the 16 Pro Max, model, OS, the script, uptime and
wall clock), `gesture` (each step change), and `touch`: one per touch per event with `t`, `g`, `id`
(the app's counter from `began` to `ended`/`cancelled`), `phase`, `type`, `x`/`y` and `px`/`py` in
points, `r` and `rTol` (majorRadius and its tolerance), `force`, `maxForce` and `taps`. The samples
UIKit coalesced into an event follow as `coalesced: true` records, so a 60 Hz delivery still shows
the 120 Hz path. The app hides the home indicator and defers the system's edge gestures; iOS can
still take a bottom-edge swipe, and that touch then logs as `cancelled`.

The app flushes at each step change and when it leaves the foreground: swipe home or lock the phone
before `pull.sh` to have the last step on disk. Launching needs the phone unlocked.

## eventtap: what the Mac's session receives

```
Tests/evidence/eventtap/run.sh                   # JSONL to stdout, Ctrl-C stops
Tests/evidence/eventtap/run.sh --out FILE        # appended to FILE
```

A listen-only session tap (`CGEvent.tapCreate`, all event types, including gesture 29, magnify 30,
swipe, smart magnify, rotate and pressure). Each record: `t`, `wall`, `type`, `x`/`y` (global, top-left
origin), `flags`, and `pid`, the posting process (`eventSourceUnixProcessID`; 0 for the hardware).
Mouse events add deltas, click state, button and subtype; scrolls add point and line deltas,
`continuous`, `scrollPhase`, `momentumPhase`; the gesture types add AppKit's `phase`, `momentum` and
`magnification`. Key downs and ups give their type and flags only, never the key.

Needs Input Monitoring. Without it the tool exits 3 and names the binary to grant
(`.build/evidence/eventtap/eventtap`), or the terminal that started it, since macOS asks about the
responsible process. A rebuild re-signs the binary ad hoc, which can cost a grant given to it.

Before a session, look for other posters: a first run on this Mac logged only `mouseMoved` events
from pid 53794, `/Applications/Jiggler.app`. Quit it, or filter its pid out.

## pasteboard: what was copied, never what it says

```
Tests/evidence/pasteboard/run.sh                 # one JSONL record per change (20 Hz poll), Ctrl-C stops
Tests/evidence/pasteboard/run.sh --once          # the current state, then exit
```

Per record: `changeCount`, the frontmost app's bundle id and pid, every item's types with `bytes`
and `sha256` each, the three nspasteboard.org markers (`concealed`, `transient`, `autoGenerated`),
which of Sill's own private types are present (`ClipboardItem.privateTypes`, compiled in from
`Sources/StreamProtocol/Clipboard.swift`) and `sillSkips`, what `ClipboardItem.skips` says. Hash the
expected text yourself (`printf %s "text" | shasum -a 256`) to recognise it. Reading each type's bytes
is what macOS 26's pasteboard privacy may ask about.

## macstate: the Mac at one moment

```
Tests/evidence/macstate/run.sh                   # pretty JSON
Tests/evidence/macstate/run.sh --line            # one line, to append to a JSONL
```

The Dock's windows from `CGWindowListCopyWindowInfo` (owner `Dock`: `layer`, `bounds`, `alpha`,
`onscreen`; the Dock itself is layer 20, the wallpapers sit at the desktop layer), the Dock's
`autohide`, `orientation` and `autohide-delay` defaults (null when unset: autohide off, bottom),
the pointer as `cg` (top-left origin) and `appKit` (bottom-left), the main display and every screen's
frame and visible frame, the frontmost app, and the pasteboard digest above. Take one before and one
after a gesture.

## dryhost.sh: a host that posts nothing

```
Tests/evidence/dryhost.sh start [SillHost flags...]   # swift build, start, print pid, port and log
Tests/evidence/dryhost.sh port
Tests/evidence/dryhost.sh stop
```

`SillHost --synthetic` with `SILL_TEST_INPUT_LOG=1`: a test pattern instead of the screen, and every
event a device's input would post printed as `Test input: left mouse down (none) at 640,1080`
instead. The log is `.build/evidence/dryhost-<time>.log`. The port is whatever free port the system
gives the home door (59640 and 59641 in two runs), never 7455, read with `lsof`. The host is not on
Bonjour, though its log still says "Advertising _sill._tcp": the `_sill._tcp` "MacBook Pro" a
browse finds is `/Applications/Sill.app`, which keeps advertising after `stop`. So a real iPhone
finds Sill.app, which posts for real, and not this host. To reach the dry host from the phone, the
Debug app's launch arguments documented in `iOSClient/ContentView.swift` should do it (not tried
with this script): `-SillConnect <Mac's address>:PORT`, or start the host with
`SILL_TEST_SERVICE_TYPE=_silltest._tcp` in the environment and launch the app with
`-SillServiceType _silltest._tcp`, e.g. `xcrun devicectl device process launch --device <udid>
me.ivor.sill.dev -SillConnect 192.168.1.20:59641`. Quitting Sill.app for the session removes the
real Mac from the list. From this Mac: `python3 Scripts/sillclient.py PORT 3 desktop --tap=0.25,0.75@1`.
